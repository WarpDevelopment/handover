# L5 smoke checklist: click and control helper (macOS, owner at the keyboard)

Acceptance 4 of lane L5. Needs a Mac, about 10 minutes. Windows is covered by CI `--selftest` only; see
`docs/recorder/evidence/L5-click-control-helpers.md`.

## Setup
1. `export PATH=/opt/homebrew/opt/node@24/bin:$PATH`
2. `npm run build:helper:mac` then `native/build/HandoverHelper --selftest`.
   Expect `hello`, `capabilities`, `selftest` lines. Without the grant, `accessibilityTrusted` is `false`.
3. Start the app from this checkout (`npm run dev`) or install the CI macOS zip.
   The helper must be at `native/build/HandoverHelper` (dev) or `Handover.app/Contents/Resources/helper/HandoverHelper`.
4. Open the doctor. Expect `helper: ok` with a version, or `no-permission` before the grant.

## A. Without the Accessibility grant
Reset first if you granted it before: System Settings > Privacy & Security > Accessibility, remove Handover and the helper.

| # | Do | Expect |
|---|----|--------|
| A1 | Start a recording. Click once in Finder, Safari and TextEdit. Stop. | Session saves; no crash. |
| A2 | Open `events.jsonl` in the session folder. | Each click is a `pointer.click` with `space: "macos_global_points"`, `unavailableReason: "permission_missing"` and **no** `target`. (If macOS refuses the event tap entirely there are no clicks but one `gap` with `reason: "permission_lost"`; note which you saw.) |
| A3 | Doctor. | `helper: no-permission`. |
| A4 | In the exported steps (once L3 is merged). | Those clicks are `visual_only` steps with `unavailable.reason: permission_missing`. |

## B. With the Accessibility grant
Grant: System Settings > Privacy & Security > Accessibility > add and enable Handover (and the helper if listed). Restart the app.

| # | Do | Expect |
|---|----|--------|
| B1 | Start a recording. In **Finder** click a sidebar item (Desktop) and a toolbar button. | `pointer.click` with `target.source: "ax"`, a `role` (for example `listitem`/`button`) and a `name` (for example `Desktop`). |
| B2 | In **Safari** click the address bar, then a link on a page. | `textbox` or `combobox` for the address bar; `link` with its text for the link. |
| B3 | In **TextEdit** click the text area and a menu bar item (File). | `textbox` (name may be empty, so `grounding: accessibility_weak`); `menuitem` named `File`. |
| B4 | In Safari open any login page and click a **password** field. | `target.isPassword: true`, `role: textbox`, the field's label as `name`, and **no value anywhere** in `events.jsonl` (search for what you typed: `grep` must find nothing). |
| B5 | Double-click a Finder item. | Second click has `clickCount: 2`. |
| B6 | Stop. Doctor. | `helper: ok`, a version, `lookupP50Ms`/`lookupP95Ms` filled, counts by grounding that add up to your clicks. P95 should be well under 300. |
| B7 | In the Terminal run `tccutil reset Accessibility` while recording is **idle**, then start again. | Behaves as section A; no system-wide input freeze (the tap is listen-only). |

## C. Helper missing
1. Rename `native/build/HandoverHelper` (dev) and start a recording, click around, stop.
2. Expect: the app records and saves normally; `events.jsonl` has one `gap` with `reason: "helper_restart"` and no `tEndMs`; doctor says `helper: missing`.
3. Rename it back.

Record what you saw, with any surprises, in the evidence file or reply to the orchestrator.
