# L4 smoke checklist: freeze, annotate, review (owner at the keyboard)

Acceptance 3 of lane L4. About 15 minutes on a Mac with two displays if you have them. Windows cannot be
tested in this lane; section E is for the Windows tester.

Legend: **Auto** = the lane ran it without a person (how is given). **Owner** = needs a person and a real screen.
Unticked boxes are for you.

## Setup
1. `export PATH=/opt/homebrew/opt/node@24/bin:$PATH`, then `npm run dev` (or install the CI macOS zip).
2. System Settings > Privacy & Security > Screen Recording: Handover enabled (the frozen frame comes from screen capture).
3. Optional, for step grounding: Accessibility (see `L5.md`).

## E. Windows (tester, 24 Nov 2026)
Not run here. Check on a laptop with a scaled display (125% or 150%) and, if you can, a second monitor with a different scale:
1. Explain covers each display fully, no gap and no overflow onto the next display.
2. Marks you draw sit exactly on what you meant (box around a button stays around the button in the exported annotated image).
3. `Ctrl+Shift+E` opens Explain; `Esc` cancels; `Enter` saves.
4. Pause and Resume as in B.

Why this is the risk: the overlay draws in CSS pixels and saves in the display's physical pixels with its scale factor
(`common/handover/overlay-geometry.ts`, tested at 100%, 125%, 150%, 200%), but mixed-DPI window placement could not be exercised.

## What the lane ran, for the record
- `npm test`: all suites green (see `evidence/L4-freeze-annotate-review.md` for counts).
- A throwaway Electron harness (not committed) loaded the built overlay and the built review screen with the real
  preload, drove them with synthetic input and took screenshots. It found that the page policy blocked `data:` images
  (fixed in `index.html`, with a test). It also led to replacing a state-updater side effect in the overlay's mark
  handling with a ref, which is sturdier; the one lost arrow it showed was a harness mistake (the drag started under the
  note card), not an overlay bug.
- A boot of the built app on macOS ran for 16 s with no error in the log.
