# Handover

A desktop recorder for Windows and macOS. Someone does a task the way they normally would, and can pause at any point to highlight what is on screen and explain it by typing or talking. Handover turns that into an open package: ordered steps, the real control behind each click, highlights, comments and narration. A fresh Claude can read the package and understand the process, and Superbrain can automate it.

Local-first: recordings stay on the user's machine until the user has reviewed and redacted every step and chosen to export.

Owned by Warp Development. First user: Moore (via Superbrain).
